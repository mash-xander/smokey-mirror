# Smokey Mirror

Быстрое шифрование файлов для Windows. Выбери файл, пароль или файл-ключ — и
получи зашифрованную копию. Работает локально, без аккаунтов и фоновой службы.

## Запуск

- **Portable:** `dist/smokey.exe`. Один файл с окном и командами.
- **С установкой:** `dist/SmokeyMirror-Setup.exe`. Устанавливает приложение для
  текущего пользователя, добавляет ярлык в «Пуск», команду `smokey` в PATH и
  действия «Encrypt with Smokey Mirror» / «Decrypt with Smokey Mirror» в меню
  Проводника. В Windows 11 они находятся в «Показать дополнительные параметры».

Сборка предназначена для Windows 10/11 x64. Цифровой подписи пока нет.
После установки открой новый терминал. Удаление — через параметры Windows или
`smokey uninstall`. Перед удалением закрой окна приложения. В версии 0.1 перед
повторной установкой нужно удалить предыдущую; пользовательские файлы и ключи
при этом сохраняются.

## Через окно

1. Перетащи файл в окно или нажми **Browse…**.
2. Выбери **Encrypt a file** или **Decrypt a file**.
3. Выбери **Passphrase** или **Key file**.
4. Введи фразу либо укажи ключ. Кнопка **Create a new key file…** создаёт новый
   ключ, который можно использовать для любого количества файлов.
5. Нажми **Encrypt file** / **Decrypt file**.

Оригинал остаётся на месте. Если имя результата занято, окно предложит новое
имя с номером. Кнопка **Show result** показывает результат в Проводнике.

Пароль при шифровании должен быть не короче 12 символов. Файл-ключ — специальный
случайный ключ Smokey Mirror / age, а не произвольная картинка или документ.
Сохраняй его резервную копию отдельно: без ключа или пароля восстановления нет.

## Через PowerShell или cmd

```powershell
.\smokey.exe encrypt "C:\Files\report.pdf"
.\smokey.exe decrypt "C:\Files\report.pdf.smoke" -o "C:\Files\restored.pdf"

.\smokey.exe keygen "E:\Keys\personal.smokey-key"
.\smokey.exe encrypt "C:\Files\report.pdf" -k "E:\Keys\personal.smokey-key"
.\smokey.exe decrypt "C:\Files\report.pdf.smoke" -k "E:\Keys\personal.smokey-key" -o "C:\Files\restored.pdf"
```

Без `-k` программа запросит пароль со скрытым вводом. Для автоматизации есть
`--password-stdin`; не записывай настоящий пароль прямо в команду терминала.
В CLI существующий результат вызывает ошибку: укажи другое имя через `-o`.

## Что внутри

Go, нативное окно Windows, библиотека age. Содержимое защищено
ChaCha20-Poly1305; пароли обрабатываются scrypt, ключи используют X25519.
Файлы `.smoke` совместимы со стандартной утилитой age.

Ошибочный пароль, повреждение или обрезанный файл не создают готовый результат.
Во время расшифровки используется временный файл с ограниченными правами;
аварийное завершение процесса может оставить его на диске. Это не средство
безопасного удаления, а оригиналы намеренно сохраняются. Подробности —
[SECURITY.md](../SECURITY.md).

Папки предварительно упаковывай в архив. Лейблы и массовая расшифровка описаны
в [плане развития](ROADMAP.md) и не включены в первую версию.

## Сборка

```powershell
go test ./...
go vet ./...
.\scripts\build.ps1
.\scripts\smoke.ps1
```

Нужен Go 1.26+. Проверенный toolchain указан в `go.mod`. Результаты сборки
и контрольные суммы находятся в `dist`.
