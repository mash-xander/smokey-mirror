# Changelog

## 0.1.1 — 2026-11-01

- Replace the application icon with the owner's artwork, including multiple Windows icon sizes.
- Add a dark palette with turquoise primary actions, gold key creation, and visible keyboard focus.
- Preserve native control behavior and the existing file encryption workflow.
- Keep `docs/` and `dist/` local and excluded from Git tracking.

## 0.1.0 — 2026-10-27

- Native Windows GUI with drag and drop, progress, cancellation, and safe output names.
- CLI encryption, decryption, key generation, hidden passphrase prompts, and stdin input.
- Standard age encryption with passphrases or generated X25519 key files.
- Authenticated streaming, protected temporary files, and non-overwriting publication.
- Per-user setup executable, Start menu shortcut, Explorer actions, PATH, and uninstall.
- Windows/Linux checks, release build script, executable smoke checks, and documentation.

Labels and batch operations are deferred to a separate release.
